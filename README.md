# unidocs

Offline Android-приложение для чтения и работы с документами: офисными файлами, PDF, Markdown, книгами, почтой и календарями. Документы обрабатываются на устройстве; обязательной учётной записи, облака и телеметрии нет.

## Возможности

- Открывает файлы через системный выборщик Android и хранит только список недавних документов.
- Показывает PDF, поддерживает заполнение AcroForm и вставку факсимиле.
- Читает EPUB, FB2, MOBI/AZW3, CBZ и CBR: темы, оглавление, закладки, позиция и поиск по книге.
- Открывает Markdown с предпросмотром по умолчанию, редактором, Mermaid и сохранением через SAF.
- Рендерит документы Microsoft Office и OpenDocument локально, без отправки файла на сервер.
- Показывает HTML/MHTML, письма EML, события ICS, CSV, XMind и встроенные preview iWork.

## Форматы

| Группа | Форматы | Режим |
|---|---|---|
| PDF | `.pdf` | просмотр, AcroForm, факсимиле |
| Markdown и текст | `.md`, `.markdown`, `.txt`, `.log` | просмотр и редактирование |
| Электронные книги | `.epub`, `.fb2`, `.mobi`, `.azw3`, `.cbz`, `.cbr` | чтение |
| Microsoft Office | `.docx`, `.xlsx`, `.xls`, `.xlsm`, `.pptx` | просмотр |
| OpenDocument и MyOffice | `.odt`, `.ods`, `.odp`, `.odg`, `.fodt`, `.fods`, `.fodp`, `.fodg`, `.xodt`, `.xods`, `.xodp` | просмотр |
| Legacy Office | `.doc`, `.rtf` | просмотр текста и базового форматирования |
| Веб, почта и календарь | `.html`, `.htm`, `.mhtml`, `.mht`, `.eml`, `.ics` | просмотр |
| Таблицы и карты | `.csv` (таблица или исходный текст), `.xmind`, `.xboard` | просмотр |
| Apple iWork | `.pages`, `.numbers` (включая `.numbes`), `.key`, `.keynote` | встроенный preview документа |

`.ppt` распознаётся, но для корректной отрисовки нужен отдельный конвертер. Его пока нет: приложение не подменяет результат пустым экраном или искажённым документом.

## Ограничения просмотра

unidocs делает ставку на небольшой автономный APK. Поэтому сложная вёрстка может отличаться от Microsoft Office, LibreOffice или iWork:

- `.doc` поддерживает текст и абзацы, но не таблицы, изображения и полное оформление;
- `.rtf` рендерит текстовое оформление; таблицы и встроенные изображения пока не выводятся;
- `.pages`, `.numbers` и `.key` показываются по preview, встроенному автором файла;
- офисные документы пока открываются только для просмотра. Редактирование доступно для Markdown и PDF-форм.

## Приватность и безопасность

Файлы открываются локально через Storage Access Framework. Встроенные WebView работают в изолированном контексте: сетевые ресурсы из открытого документа не загружаются, а внешние ссылки передаются системному браузеру только по действию пользователя.

## Сборка

Нужны JDK 17 и Android SDK с `platforms;android-35`.

```powershell
.\gradlew.bat :app:assembleRelease
```

Подписанный release собирается, если параметры `signing.*` заданы в локальном `local.properties`. Ключ подписи не входит в репозиторий. APK появляется в `app/build/outputs/apk/release/` с именем `unidoc-v<version>-release.apk`.

Для проверки модулей:

```powershell
.\gradlew.bat :app:testDebugUnitTest :feature:office:testDebugUnitTest :feature:books:testDebugUnitTest
```

## Технологии

Kotlin, Jetpack Compose, Android WebView, AndroidX PDF, PDFBox-Android, CommonMark, Foliate JS, docx-preview, SheetJS и PPTXjs. Сторонние JS-компоненты и их лицензии поставляются в assets соответствующих модулей.

## Статус

v1.5 (22.11.2026): найдена корневая причина неработающих книг — в вендоренном foliate-js не было `vendor/zip.js` (все ZIP-форматы падали на `import`, молча давая белый экран). Добавлен собственный shim (4 КБ: STORE + DEFLATE через DecompressionStream, WebView 103+). fb2 теперь конвертируется в EPUB самим reader (свой store-zip, валидация кодировок, ошибки видны баннером); legacy .doc читается своим CFB/Word-ридером (текст и абзацы). 


Проект активно развивается. Сообщения о файлах, которые не открываются или отображаются неверно, особенно полезны вместе с версией приложения, версией Android и обезличенным примером файла.
